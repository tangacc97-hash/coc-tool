# CoC Tool (v0.1 – khung ban đầu, CHƯA test)

## Build APK (không cần máy tính mạnh)
1. Tạo repo GitHub, upload toàn bộ thư mục này (nhớ cả thư mục `.github`).
2. Tab **Actions** → chạy "Build APK" → tải `CocTool-apk` ở mục Artifacts → giải nén → cài `app-debug.apk`.
(Hoặc mở bằng Android Studio → Build > Build APK.)

## Cài đặt
- Cần Android 11+. Nếu nút Trợ năng bị mờ: Cài đặt > Ứng dụng > CoC Tool > ⋮ > "Cho phép cài đặt bị hạn chế".
- Bật Trợ năng → vào game (chế độ ngang) → bấm nút ▶ nổi ở mép phải.
- Tọa độ mặc định là ƯỚC LƯỢNG: dùng "Chụp thử" rồi chỉnh mục Tọa độ.

## Đã có
Đấu thưởng/farm (lọc loot bằng OCR, thả lính, đầu hàng), spam đầu hàng, đổi acc theo số trận / kho đầy,
chỉ xin lính, chỉ cho lính (cơ bản), nút nổi bật/tắt, chụp thử + OCR.
